# Statisk nettside

Planlagt struktur:
- `index.html` – midlertidig, enkel publiseringsside (erstattes etter at design er avklart)
- `pages/` – undersider
- `assets/css/` – stilark
- `assets/js/` – enkel JavaScript ved behov
- `assets/images/` – godkjente bilder
- `assets/fonts/` – fonter med gyldig lisens

Ingen rammeverk eller ferdig nettside er valgt. GitHub Pages publiseres via `.github/workflows/deploy-pages.yml` ved push til `main`.
