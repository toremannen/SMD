# Dokumentasjon

- `NETTSIDEPLAN.md`: foreløpig utviklingsplan.
- `decisions/`: korte beslutningsnotater med dato.
- `meetings/`: interne møtenotater uten personopplysninger eller konfidensielt innhold.
- `design/`: godkjente designnotater og skisser.

Sensitive dokumenter skal i `local-private/` og ikke pushes til GitHub.
